# Inventory Management Dashboard — Power BI

## Overview
Interactive Power BI dashboard analyzing inventory, revenue, and 
reorder patterns across 5 product categories and 6 suppliers.

## Dataset
- 21,200 transaction rows
- 4 tables: Products, Suppliers, Transactions, Calendar
- Star schema data model

## Key Features
- KPI cards: Revenue (128.4M), Gross Margin (40.4%), Inventory Value (178.5M)
- Conditional formatting on reorder status (Green = Stock OK, Red = Reorder Needed)
- Sales trend analysis by Year, Quarter, Month and Day
- Supplier-wise product distribution analysis
- Category slicer for dynamic filtering

## Tools Used
Power BI Desktop, DAX, Excel
